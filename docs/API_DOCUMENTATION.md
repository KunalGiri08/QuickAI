# QuickAI API Documentation

This document describes all implemented HTTP endpoints of the **QuickAI** REST API.

---

## 1. Global Conventions

### 1.1 Base URL
- **Local Development**: `http://localhost:3000`
- **Production**: Configured via the `VITE_BASE_URL` client environment variable.

### 1.2 Authentication Header
All routes under `/api/*` are guarded by Clerk authentication (`clerkMiddleware()` and `requireAuth()`). Requests must include a valid Clerk session token in the HTTP `Authorization` header:

```http
Authorization: Bearer <clerk_session_jwt_token>
```

### 1.3 Response Format
All API responses adhere to a consistent JSON envelope structure:

```json
{
  "success": true,
  "content": "Result payload or URL",
  "message": "Optional status message"
}
```

In the event of an error:

```json
{
  "success": false,
  "message": "Detailed error message"
}
```

### 3.2 AI Article Generator

#### `POST /api/ai/generate-article`
- **Purpose**: Generates high-quality, long-form articles in Markdown format based on topic and target length.
- **Authentication**: Required (`Bearer <token>`).
- **Quota / Permissions**:
  - Free users: Allowed up to 10 free generations total across text tools (tracked in `user.privateMetadata.free_usage`).
  - Premium users: Unlimited generations.
- **Content-Type**: `application/json`

**Request Body**:
```json
{
  "prompt": "Write an article about The Future of Artificial Intelligence in Short (500-800 words)",
  "length": 800
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `prompt` | String | Yes | Complete instruction prompt for the article topic and tone. |
| `length` | Number | Yes | Numeric target length: `800` (max 3000 tokens), `1200` (max 4000 tokens), or `1600` (max 5000 tokens). |

**Success Response (200 OK)**:
```json
{
  "success": true,
  "content": "## The Future of Artificial Intelligence\n\nArtificial intelligence continues to evolve..."
}
```

**Error Responses**:
- Limit reached (Free plan):
  ```json
  {
    "success": false,
    "message": "Limit reached. Upgrade to continue."
  }
  ```
- Failure:
  ```json
  {
    "success": false,
    "message": "Failed to generate article."
  }
  ```

**cURL Example**:
```bash
curl -X POST http://localhost:3000/api/ai/generate-article \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <CLERK_TOKEN>" \
  -d '{"prompt": "Write an article about Quantum Computing in Short (500-800 words)", "length": 800}'
```

### 3.4 AI Image Generator

#### `POST /api/ai/generate-image`
- **Purpose**: Generates an image from a textual prompt with a chosen artistic style using the Clipdrop API, stores it in Cloudinary, and optionally publishes it to the community showcase.
- **Authentication**: Required (`Bearer <token>`).
- **Quota / Permissions**: **Premium Plan Only**.
- **Content-Type**: `application/json`

**Request Body**:
```json
{
  "prompt": "Generate an image of a cybernetic tiger in neon jungle in the style 3D style",
  "publish": true
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `prompt` | String | Yes | Description of the desired image and style. |
| `publish` | Boolean | No | Whether the image should be visible in the community feed (default: `false`). |

**Success Response (200 OK)**:
```json
{
  "success": true,
  "content": "https://res.cloudinary.com/your-cloud/image/upload/v1234567890/sample.png"
}
```

**Error Responses**:
- Non-premium user:
  ```json
  {
    "success": false,
    "message": "This feature is for premium users only. Please upgrade to access it."
  }
  ```

**cURL Example**:
```bash
curl -X POST http://localhost:3000/api/ai/generate-image \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <CLERK_TOKEN>" \
  -d '{"prompt": "Generate an image of futuristic car in the style Realistic", "publish": false}'
```

### 3.5 AI Background Removal

#### `POST /api/ai/remove-image-background`
- **Purpose**: Removes the background from an uploaded image using Cloudinary's AI background removal transformation.
- **Authentication**: Required (`Bearer <token>`).
- **Quota / Permissions**: **Premium Plan Only**.
- **Content-Type**: `multipart/form-data`

**Form Data Parameters**:
| Field | Type | Required | Description |
|---|---|---|---|
| `image` | Binary File | Yes | Image file (JPG, PNG, etc.) uploaded as multipart form data. |

**Success Response (200 OK)**:
```json
{
  "success": true,
  "content": "https://res.cloudinary.com/your-cloud/image/upload/e_background_removal/v1234567890/sample.png"
}
```

**Error Response**:
```json
{
  "success": false,
  "message": "This feature is for premium users only. Please upgrade to access it."
}
```

**cURL Example**:
```bash
curl -X POST http://localhost:3000/api/ai/remove-image-background \
  -H "Authorization: Bearer <CLERK_TOKEN>" \
  -F "image=@/path/to/photo.jpg"
```

### 3.6 AI Object Removal

#### `POST /api/ai/remove-image-object`
- **Purpose**: Erases a specified object from an image using Cloudinary Generative Inpainting (`gen_remove`).
- **Authentication**: Required (`Bearer <token>`).
- **Quota / Permissions**: **Premium Plan Only**.
- **Content-Type**: `multipart/form-data`

**Form Data Parameters**:
| Field | Type | Required | Description |
|---|---|---|---|
| `image` | Binary File | Yes | Image file uploaded as multipart form data. |
| `object` | String | Yes | Name of a single object to remove (e.g., `watch`, `car`, `chair`). |

**Success Response (200 OK)**:
```json
{
  "success": true,
  "content": "https://res.cloudinary.com/your-cloud/image/upload/e_gen_remove:watch/v1234567890/sample.jpg"
}
```

**Error Response**:
```json
{
  "success": false,
  "message": "This feature is for premium users only. Please upgrade to access it."
}
```

**cURL Example**:
```bash
curl -X POST http://localhost:3000/api/ai/remove-image-object \
  -H "Authorization: Bearer <CLERK_TOKEN>" \
  -F "image=@/path/to/table.jpg" \
  -F "object=cup"
```

  ```json
  {
```

  ```json
    "message": "File size should be less than 5MB."
  ```

  ```json
  {
    "success": false,
    "message": "This feature is for premium users only. Please upgrade to access it."
  ```

**cURL Example**:
```bash
curl -X POST http://localhost:3000/api/ai/resume-review \
```

### 3.10 Toggle Like Creation

#### `POST /api/user/toggle-like-creation`
- **Purpose**: Likes or unlikes a creation in the community showcase by appending or removing the authenticated user's Clerk ID from the creation's `likes` array.
- **Authentication**: Required (`Bearer <token>`).
- **Content-Type**: `application/json`

**Request Body**:
```json
{
  "id": 1
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | Number | Yes | Primary key ID of the target creation. |

**Success Responses (200 OK)**:
- When liked:
  ```json
  {
    "success": true,
    "message": "Creation Liked"
  }
  ```
- When unliked:
  ```json
  {
    "success": true,
    "message": "Creation Unliked"
  }
  ```

**Error Response**:
```json
{
  "success": false,
  "message": "Creation not found"
}
```

**cURL Example**:
```bash
curl -X POST http://localhost:3000/api/user/toggle-like-creation \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <CLERK_TOKEN>" \
  -d '{"id": 1}'
```
